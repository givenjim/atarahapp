## 2. What P1-M6 must change

1. **Local platform.** Install the Supabase CLI; `supabase init`; commit `supabase/config.toml` (OTP 6 digits / 600 s, password policy, refresh rotation with reuse detection, phone + TOTP MFA, Send-SMS hook, SMTP placeholder, 6-digit-token email templates). Cut `infrastructure/docker-compose.yml` down to Redis. Update `just dev` / `bootstrap`.
2. **Database.** Add `ATARAH_DIRECT_URL` (migrations) beside the pooled `ATARAH_DATABASE_URL`; replay all 8 migrations on a fresh Supabase database; add SQL migrations for the `auth.users` triggers and FK, RLS on every table (deny-all), a dedicated NestJS database role, the `notifications` Realtime publication and its single `SELECT` policy; add `scripts/check-rls.sql` to CI; write `scripts/migrate-dev-data.ts`.
3. **Authentication.** Add `SupabaseAuthGuard` (JWKS verification, load `public.users` by `sub`, reject suspended/deactivated/deleted). Move sign-up, verify, resend, sign-in, recovery, sign-out in the mobile app to `supabase_flutter` (auth only), keeping every screen and string. Add `GET/DELETE /auth/sessions` (service role), `POST /auth/hooks/send-sms` (signature-verified), `user_devices`. Admin app moves to Supabase Auth + TOTP with AAL2 on `/admin/*`. Then remove the replaced endpoints and the `credentials`, `sessions`, `verification_codes`, `admin_totp` tables, **dev and staging only**.
4. **Storage.** Supabase Storage adapter behind the existing storage interface, three buckets, signed upload/download URLs with the same API shape; migrate dev media; the media job reads and writes Supabase Storage.
5. **Realtime.** The app subscribes to its own `notifications` inserts for the unread badge.
6. **Tests/CI.** Integration tests run against the local Supabase stack plus Redis instead of Testcontainers PostgreSQL; real Supabase Auth flows; RLS check; an anon-key-denied test; a Realtime delivery test.
7. **Docs/env.** `.env.example` for every app, `ARCHITECTURE.md`, `DEVELOPMENT.md`, `SECURITY.md`, `DATABASE.md`.
8. **Gap-fill** (section 3).
