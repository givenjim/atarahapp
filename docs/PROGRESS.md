## Known risks

- Push delivery through Google FCM is not verified: no Firebase credentials exist (DEC-030). Only request building and invalid-token handling are tested against a fake client.
- `.github/workflows/ci.yml` parses as YAML and every command in it was run locally, but the workflow has never run on GitHub.
- Golden images were generated on Windows; the first Linux CI run may need `flutter test --update-goldens` once (0.5% tolerance is in place).
- Abandoned `PENDING_UPLOAD` media rows and orphan objects are not cleaned up yet (DEC-029; scheduled for P3-M5).
- Windows development host: `just` is used instead of Makefile (DEC-002). iOS builds cannot be produced on Windows, so iOS is reported as "not verifiable on this host".
- Backend integration suites time out under heavy machine load (default 5 s hook timeout) and need Docker Desktop running.
